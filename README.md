# Midget Sani — ElizaOS Character File

![Bitcoin Obama Podcast banner](banner.jpg)

Midget Sani, Bitcoin Obama's midget: the man with dwarfism who stars in his promo videos and appeared on episode 6 of The Crypto Craic Podcast.

**Midget Sani** is part of the Bitcoin Obama universe — the world of Bitcoin Obama and The Crypto Craic Podcast (The Bitcoin Obama Podcast), documented on [bitcoinobama.com](https://bitcoinobama.com). This repository is Midget Sani's official **ElizaOS character file**: bio, lore, message examples, post examples and speaking style for running Midget Sani as an autonomous ElizaOS agent.

## File

- `midget-sani.elizaos.character.json` — the complete ElizaOS character definition.

## Run them

`elizaos start --character midget-sani.elizaos.character.json`
